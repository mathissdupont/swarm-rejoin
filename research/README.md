# Research workspace

Begin with the [literature protocol](../docs/03-literature-review-protocol.md). The registry and matrix track starting references; they do not represent completed team reviews.

Use the [paper note](templates/paper-note.md), [experiment report](templates/experiment-report.md), [meeting note](templates/meeting-note.md), and [decision record](templates/decision-record.md) templates. Copy a template into a dated/topic-specific file and replace placeholders with evidence. Never turn a planned meeting or experiment into a completed record without doing it.

Store downloaded papers outside Git unless redistribution is permitted. Link to persistent identifiers and record the version and reading depth. Keep all authored research notes in English.
